# Plans

* [A Component Inserter](A-Component-Inserter.md) - An Obsidian command that scaffolds the right block — HTML, codefence, callout, embed — at the cursor, with frontmatter-driven defaults.
* [Auto-Hyperlink Feature Names in Generated Tables](Auto-Hyperlink-Feature-Names-In-Tables.md) - Crawls the entity's domain to turn feature-table cells into links to the real feature pages — deferred until the headless crawler exists.
* [Cite-Wide — dedupe inline repetition of identical hex citations](Cite-Wide-Dedupe-Inline-Repetition.md) - One backreferenced regex collapses runs like [^jtas3k] [^jtas3k] — a different problem from dedupe-by-URL, which must stay untouched.
* [Create a Study of the Best Obsidian Plugins](Create-a-Study-of-the-Best-Obsidian-Plugins.md) - Pin the 10–15 most interesting Obsidian plugins as a real study, so we read their code instead of paraphrasing from training data.
* [Dependency upgrades across the Obsidian plugin family — full bump inventory, safe → major → forks](Dependency-Upgrades-Across-Plugin-Family.md) - Every outdated dependency in the ten Lossless-original modules plus the umbrella, grouped patch → minor → major, with upstream release-notes research attached to every major before it moves.
* [Image Drop Confirmation Gate](Image-Drop-Confirmation-Gate.md) - An Obsidian plugin that asks where a dropped image goes before anything hits disk or network — a private chart on imgur is a phone call.
* [Plan — Migrate the Lossless Plugin Family to Obsidian 1.13](Migrate-Plugin-Family-to-Obsidian-1-13.md) - Obsidian 1.13 changed how settings render and get searched, and pnpm 11 changed where its settings live. One playbook, nine plugins, each still standing on its own.
