Pull Open Graph metadata from any URL — title, image, description, publisher, site name — straight into your note's YAML frontmatter. Two providers (OpenGraph.io for rich hybridGraph returns, Microlink for speed), both with free tiers. Per-file fetch from the active note or batch fetch across a directory of stubs. Downstream tooling — Dataview, Bases, custom queries — then treats every URL you've saved as structured data, not opaque link text.
