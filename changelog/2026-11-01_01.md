# Content Farm's Plugin Docs Become a Bundle Any Agent Can Read

## Why Care?

`content-farm/context-v/` holds the shared thinking behind the whole Obsidian plugin family: how plugins call models, how they pass marketplace review, how the family upgrades together, and the issues that cut across more than one plugin. Until today an agent landing here had to open each doc to learn what kind of doc it was. Now the folder is an Open Knowledge Format (OKF) v0.2 bundle, and any OKF reader can list what's here and what each doc is for without opening a thing.

## What's New?

- **All 31 docs in folders declare their `type`**, the Train-Case name of the folder they live in: `Plans`, `Issues`, `Explorations`, `Specs`, `Chores`, `Handoffs`, `Reminders`, `Blueprints`, `Loops`, `Prompts`. 23 had no `type` at all.
- **Eight lowercase types now match their folders:** `type: issue` became `Issues`, and likewise for `plan`, `spec`, and `exploration`. OKF wants the folder's name, so this restores the rule rather than changing what any doc is.
- **`context-v/index.md`** marks the bundle with `okf_version: "0.2"` and lists its ten folders.
- **Ten new folder indexes**, one line per doc with its lede.
- **The splash skips `index.md`** when loading `context-v/`, its own and every rolled-up plugin's, so the indexes stay navigation for agents and don't become pages. The splash builds clean with the change.

## Under the Hood

- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan, [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand, one file at a time. The doc diff is 31 `type:` lines (23 added, 8 re-cased) and nothing else. No dates moved: this is a compliance change, not a content change.
- `context-v/Migrating-when-an-API-Provider-Rebrands.md` sits at the bundle root, not in a folder, so it carries no `type`. It is waiting to be filed.
- `context-v/studies/Textgenerator-Analysis.md` was left as found (`type: study`); the sweep doesn't touch anything under a `studies/` folder.
- The plugins under `plugin-modules/` are their own repos and their own bundles, swept in their own commits.
