# Funding Rounds in Your Notes, and Citations Ready to Publish

## Why Care?

Funding is where a research model is most likely to be confidently wrong: round sizes get rounded, lead investors get swapped, and a company with a similar name slips in. And once a note was generated, it still took hand-editing before its sources could go out.

Over two days, three of our Obsidian plugins took on both problems. Company notes can now start from checked funding data, and the citations at the bottom arrive complete.

## What's New?

| Plugin | Version | What changed | Status |
|---|---|---|---|
| **Perplexed** | 0.5.0 | Fireround funding rounds as citeable sources, with the raw data written into the note | Released |
| **Perplexed** | 0.5.1 | One publish-ready citation format, and raw source lists stay out of your notes | Released |
| **Cite Wide** | 0.3.2 | The citation spec now matches how we cite. Docs only, no plugin code changed. | Released |
| **Metafetch** | 0.2.0 | Fill fields from any data API, and a Fetch via Fireround command | Written, release not published |

### Perplexed

- **Funding rounds from [Fireround](https://fireround.dev).** With `write-json-under: "Fundraising History"`, a company profile carries the rounds exactly as they arrived, and each round becomes its own `[^F1]` source for the writing model to cite.
- **Citations that arrive complete.** Fireround, Exa and Perplexity sources now share one format:

  ```md
  [^F1]: 2019, Sep 10. [PR Newswire](https://www.prnewswire.com/). [Samsara raises $300 million in new growth capital…](https://www.prnewswire.com/news-releases/…). Generated: 2026, Nov 01. [Fireround](https://fireround.dev) API response.
  ```

- **No more raw sources block.** Models kept copying the prompt's `## Retrieved sources` list into the top of the note. The prompt now tells them not to, and Perplexed removes any copy that gets through.
- **Dates no longer land a day early** anywhere west of Greenwich.

### Cite Wide

The Lossless citation spec lives here, and it picked up two rules from the Perplexed work:

- The publisher comes before the title.
- `Accessed` means a person went to the source. When a tool retrieved it during a run, the citation says `Generated:` with the date of that run and credits the provider last.

Cite Wide's own citation output hasn't changed to match yet.

### Metafetch

- **Fields from any data API.** A Tooling note can fill its latest round and lead investors from Fireround, and its brand colours and fonts from Firecrawl.
- **A fallback for sites that refuse a plain fetch.** `from: [direct, firecrawl]` reads the page directly first and asks Firecrawl only if that fails.
- **Fetch via Fireround.** One command writes a company's rounds under `## Fundraising History`.
- **New APIs without a new release.** Any other JSON API is a recipe file in your vault.

## How the Plugins Fit Together

Perplexed and Metafetch both write Fireround data the same way: a `json` block under the same heading, so whichever runs second updates the block instead of adding another. Both read the Firecrawl key from Obsidian's keychain, so they can share one secret.

Both are also careful about whose rounds they write. They only look up a company's homepage, because a note on `openai.com/sora` is about something hosted on that domain, and the host's rounds don't belong to it. Perplexed also keeps only exact domain matches, so a similarly named company's rounds never get attributed to a note.

## What We Learned

**Perplexity's source dates can't be trusted as publish dates.** Its docs describe `date` as when a page was originally published, so 0.5.1 prints it that way. When we checked four citations on a Samsara note against the real pages, two were correct and two were wrong, one by four months. A homepage and a pricing page also got publish dates, and some pages were "updated" before they were "published". Fireround dates come from its own round records and aren't affected.

We're leaving this as it is for now, so treat the leading date on a Perplexity citation as unverified. The options on the table are dropping those dates, or filling in real ones later through Cite Wide.

**"Accessed" was the wrong word.** We wrote it first, then changed it, because it claims a person read the page and nobody had.
