# Screenshots, Images, and Funding Rounds That Arrive

## Why Care?

The worst bugs are the quiet ones. Three things in our plugins had stopped working without a single error: Perplexed notes came back without images, company notes came back without funding rounds, and Image Gin's Magnific search got so slow it looked broken. Each one just made a note a little worse than it should have been.

All three are fixed. And the `## Screenshots` section our toolkit notes always asked for, and almost never got, now has two commands that fill it.

## What's New?

| Plugin | Version | What changed | Status |
|---|---|---|---|
| **Perplexed** | 0.6.0 | Images return through Perplexity's image search; Fetch screenshots from website; Fireround finds rounds by exact domain; Claude Opus 5.5 by default | Released |
| **Metafetch** | 0.3.0 | Fetch screenshots from website: captures the site, saves the image in your vault | Released |
| **Image Gin** | 0.3.1 | Magnific search returns your configured count instead of 50, over https | Released |

## Two Screenshot Commands, On Purpose

Both plugins now have a command called **Fetch screenshots from website**, and they find different things:

| | Metafetch | Perplexed |
|---|---|---|
| **What you get** | The homepage as it looks today | The product screenshots the company publishes |
| **How** | Microlink renders the page | Perplexity's image search, limited to the company's domain |
| **Stored** | Saved in your vault | Linked from the company's site |
| **Cost** | Free for about 50 a day | Your Perplexity key |

They write to `## Screenshots` with the same rule: add after any images already there, replace a placeholder. Run both and a note gets the homepage plus the product shots. Each plugin carries its own copy of that rule, because each ships on its own.

## What We Learned

**Perplexity's Sonar API stopped returning images, and didn't say so.** Requests to Sonar Chat Completions are now rewritten for Perplexity's Agent API, which has no `return_images`. The request still succeeds; the images just aren't there. The Agent API's `image_search` tool brings them back, as long as you force it on: left to choose, the model usually skipped it. We wrote this up as a keeping-up post, *Perplexity Sonar Pro Images Deprecated*.

**Fireround's search is free text.** Searching it for a domain found only companies whose domain appeared in their text. Its `companies/rounds` capability looks a company up by exact domain, which is what we wanted all along.

**APIs ignore parameters they don't know.** Magnific has never accepted `per_page`. It returned its default of 50 every time, and nothing complained.

## What's Next?

- Rewrite Perplexed's *Find images for selection* for the Agent API. It still returns no images.
- Move Perplexed fully to Perplexity's Agent API before Sonar Chat Completions ends.
